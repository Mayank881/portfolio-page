# 💼 Personal Portfolio Website

This is a responsive and elegant **Personal Portfolio Website** built using **HTML**, **CSS**, **SCSS**, and **JavaScript**. It is designed to showcase my projects, skills, experience, and contact information in a professional and interactive manner.

## 🚀 Features

- Fully responsive design (mobile-first)
- Smooth scroll and animation effects
- Skills and tools section
- Projects with descriptions and links
- About me and experience timeline
- Contact form and social links

## 🛠️ Tech Stack

- HTML5
- CSS3 / SCSS
- JavaScript
- Prepros (for SCSS compilation)
